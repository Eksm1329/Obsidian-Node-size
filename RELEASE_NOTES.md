Folder Node Size 1.0.0

- Folder-wide graph node size rules, with optional subfolders.
- Deepest-folder priority, automatic-size exceptions and individual note overrides.
- Rules follow renames and apply to future notes.
- Global and local graph support; responsive English settings for mobile.
- Separate plugin ID: folder-node-size. Disable the original Node Factor before use.

Download main.js, manifest.json and styles.css into .obsidian/plugins/folder-node-size/ in your vault. See README for iPhone installation and a device test checklist.

Build and automated rule/renderer tests validated. Real Obsidian UI and iPhone/Android behavior require device testing; the graph renderer API is internal.
